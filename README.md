# Freeze 
**📢本项目github地址：https://github.com/codecodegogogo/Freeze**

**📢本项目xposed仓库地址：https://github.com/Xposed-Modules-Repo/io.github.codecodegogogo.Freeze**

Freeze 是基于 [Hail](https://github.com/aistra0528/Hail) 修改的 Android 应用管理工具，支持停用、隐藏、暂停和强行停止应用。默认桌面名称为“Freeze”，包名为 `com.aistra.calendar`，首次打开会直接进入管理界面。

> 操作系统应用可能导致设备异常，严重时无法正常开机。请提前确认可通过 ADB、Root 或 Recovery 恢复。

完整更新说明见 [CHANGELOG.md](CHANGELOG.md)。

## 快速开始

1. 打开应用，进入管理界面。
2. 前往“设置 > 权限”，选择 Root、Shizuku、Dhizuku、设备所有者、炼妖壶或特权系统应用。
3. 在“默认模式”中选择该权限支持的冻结方式。
4. 前往“设置 > 添加操作应用”，选择应用后点击“下一步”。
5. 选择目标分组并确认，应用才会加入首页。

应用选择采用草稿模式：直接返回或取消不会写入首页；只有确认后才会保存。

## 首页与应用管理

- 点击应用图标启动应用。若应用已冻结，会先尝试恢复再启动。
- 长按应用可冻结、恢复、设置定时任务、置顶、加入白名单、管理标签、复制包名或移出首页。
- 应用可按名称、首次安装时间或最近更新时间排序，并可筛选用户应用、系统应用、已冻结或未冻结应用。
- 已卸载但仍保留在首页的记录会排在正常应用之后，可长按移除以清理。
- 首页支持搜索、多选和标签管理；搜索支持模糊匹配及中文拼音匹配。
- 长按应用打开详情面板：顶部为应用图标、名称和应用信息按钮，下方为启动按钮与双列操作卡片。
- “添加标签”“筛选与排序”“选择分组”弹窗采用统一圆角面板，支持深浅主题；选择分组时可直接新建分组。

## 标签与独立模式

- 同一个应用可以加入多个标签。
- 长按标签可重命名，并为标签选择独立模式。
- 标签独立模式优先于设置中的默认模式。
- 标签只展示当前权限支持的操作。
- 应用属于多个独立模式标签时，按首页标签顺序使用第一个匹配项。
- “全部冻结 / 全部解冻”会按各标签模式分别执行。

例如默认模式为“停用”时，可让 A 标签继续使用停用，让 B 标签使用隐藏；批量操作会分别执行并显示对应结果。

## 权限与模式

| 权限 | 强行停止 | 停用 | 隐藏 | 暂停 |
| --- | :---: | :---: | :---: | :---: |
| Root | 支持 | 支持 | 支持 | 支持 |
| Shizuku | 支持 | 支持 | 支持 | 支持 |
| Dhizuku | 不支持 | 不支持 | 支持 | 支持 |
| 设备所有者 | 不支持 | 不支持 | 支持 | 支持 |
| 炼妖壶 / Insular | 不支持 | 不支持 | 支持 | 支持 |
| 特权系统应用 | 支持 | 支持 | 不支持 | 不支持 |

- **强行停止**：结束当前进程，但应用之后仍可能重新启动。
- **停用**：应用无法运行，桌面入口通常消失，可通过启用恢复。
- **隐藏**：从启动器和普通应用列表中隐藏，可通过取消隐藏恢复。
- **暂停**：限制用户启动并隐藏通知，但不保证后台进程完全停止。

实际支持情况受 Android 版本、系统限制和授权方式影响。例如部分非 Root 的 Shizuku 环境无法执行隐藏。切换权限或标签模式前，建议先恢复已经处理的应用。

## 界面与设置

- 首页、设置和关于页使用大号左对齐标题。
- 标签使用纯白或纯黑背景，选中状态使用反色。
- 快捷冻结按钮可放在底栏或首页右下角，默认位于首页右下角。
- 底栏中的首页、设置和快捷按钮等宽排列；快捷按钮默认灰色，按下时变为前景色。
- 首页快捷按钮可展开冻结操作气泡；其他页面的快捷按钮会提示“此页不可用”。
- 右下角按钮随深浅模式反色，展开气泡时仅应用图标区域轻模糊，搜索框和标签保持清晰。
- 冻结应用显示冰块角标，冰块大小随首页图标大小缩放。
- 设置中的“外观和触感”包含主题、悬浮底栏、快捷按钮位置、图标大小、字体大小、无字模式和触感。
- “触感”默认开启，点击主要图标会提供轻量震动反馈。
- 关于页底部支持检查更新，读取 GitHub 最新 Release 并打开发布页。
- 设置中的“自定义”包含模糊搜索和终端。

首页图标支持每行 3–8 个，并会根据数量自动缩放；字体大小可在 11–16 之间调整。

## 日历伪装

- “启用日历隐藏”默认关闭；开启后桌面入口显示为“万年历”，启动时先进入日历页面。
- 应用启动时会按开关同步桌面入口，关闭时显示 Freeze 雪花图标，开启后显示日历图标。
- 日历支持阳历、农历显示和左右滑动切换月份。
- 解锁方式：双击年份，然后在 3 秒内长按月份。
- 解锁后，本次运行期间不再显示日历；重新打开应用后会恢复伪装。
- 关闭该功能后，桌面名称和图标恢复为 Freeze，启动时直接进入管理界面。

## 备份与恢复

“设置 > 备份与恢复”支持导出和恢复 JSON 备份，内容包括：

- 全部设置。
- 首页应用列表，以及应用的置顶、白名单和标签归属。
- 全部标签及其独立模式。

恢复前会要求确认，恢复完成后会重新加载设置和列表。

## MiPush 通知

Freeze 直接移植了 New MiPush Enhance 的 Java 接收与点击代码，使用传统 Xposed 入口，不再依赖独立模块。

- “设置 > 自定义 > MiPush”默认关闭。
- 在 LSPosed 中启用 Freeze 模块，并勾选“系统框架”和“小米服务框架”。
- 接收通知时不解冻应用；点击时解冻目标应用、清除停止状态，并重放原通知的跳转请求。
- 首次发送失败后，依次等待 1.6 秒、0.9 秒重试；仍失败时保留原通知的页面参数进行启动，服务类通知则解析 MiPush 的页面、Intent 或网页跳转信息。
- 该能力主要适配 Root 停用模式；应用本身必须接入 MiPush。
- 未接入 MiPush 的应用不会因此收到推送。
- 模块声明使用 `xposedminversion=82`，走标准传统模块路径；从旧实现升级时，在 LSPosed 中重新启用 Freeze，确认作用域后重启，再打开 Freeze 一次同步开关。测试时不要同时启用独立的 New MiPush Enhance 模块。

源码来自 [New-MiPush-Enhance](https://github.com/codecodegogogo/New-MiPush-Enhance)。保留原版接收器查询的占位返回值，不新增安全中心作用域；不包含原模块的自动冻结策略。桌面作用域仅供原有的桌面启动解冻使用。

`python tools/mipush_reference.py` 可与本地原项目核对移植代码；原版方法指纹也纳入单元测试，避免再次改写通知处理链路。

## 按需解冻

- “设置 > 自定义 > 按需解冻”默认关闭。
- 开启后，被停用的应用会重新参与链接解析：浏览器或其他应用打开指向该应用的链接时，会识别到已安装的冻结应用，而不是提示未安装或引导下载。
- 真正打开链接时只解冻目标应用并清除停止状态，其他应用保持冻结。
- 需要在 LSPosed 中启用 Freeze 模块并勾选“系统框架”；关闭开关后立即恢复系统原有行为。
- 主要适配停用模式。隐藏模式的应用对系统完全不可见，无法参与链接解析；暂停模式会在启动前自动取消暂停。

## 与原版的差异

- 使用 Miuix 和 Compose 重构管理界面，移除 Fragment、RecyclerView 和旧 XML 布局。
- 将工作模式拆分为“权限”和“默认模式”。
- 增加标签独立模式和日历伪装。
- 应用选择页增加草稿选择、筛选排序、目标分组确认流程。
- 使用新的白底黑色雪花图标、Freeze 品牌和 `2.4.0` 版本。
- APK 文件名为 `Calendar-v版本号.apk`。

已移除图标包、灰度图标、紧凑图标、合成自适应图标、T9 九键搜索、快捷方式设置、快捷设置磁贴、无图标应用启动器、自动操作功能、首页右上角批量菜单、关于页捐助入口，以及底部导航栏中的“应用”和“关于”按钮；关于页的群组、QQ 群、F-Droid 和翻译入口也不再提供。
